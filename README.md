# Roommate Pick'em Showdown

Live site: https://danielbaddoura-alt.github.io/pickem/

- **Making picks:** open the site, tap your name, tap a team for each game, then hit **Save**. Each game locks at kickoff.
- **Scores:** pulled from ESPN automatically, and refreshed every minute while games are live.
- **Odds:** each game's ESPN moneyline is saved the first time someone picks that game.
- **Storage:** picks are saved in the Firebase project `roommate-pickem`, on Daniel's Google account.
